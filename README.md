# UiTM data notebooks

Data analysis notebooks (Python, pandas, Jupyter) with Tableau workbooks, from two UiTM courses in the Bachelor of Information Technology (Hons.).

| Folder | Course | What it looks at |
|---|---|---|
| `premier-league-2018/` | ICT550 Principles of Data Management, 2021 (individual lab assignment) | The 2018 Premier League season |
| `airline-reviews-sentiment/` | ICT550, 2021 (individual lab assignment) | Sentiment in airline reviews |
| `ebay-used-cars/` | ICT550, 2021 (group project) | Used-car listings from eBay |
| `kl-property-listings/` | DSC650 Data Technology and Future Emergence, 2022 | Property listings in Kuala Lumpur |

The airline reviews CSV (54 MB) is not included; the other datasets are in each folder's `assets/`.
